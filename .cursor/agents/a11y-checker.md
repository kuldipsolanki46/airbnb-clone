Audit accessibility only: skip link, focus traps and focus restore in all
dialogs (`PhotoTour`, `Lightbox`, `Modal`), Esc handling, lightbox arrow
keys, `aria-modal`/`aria-label`/`aria-pressed`/`aria-expanded` correctness,
alt text, focus-visible styles, and `prefers-reduced-motion`. List issues
by severity with the component that owns each fix.
